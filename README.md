# Professor Flash V1

یک Agent هوش مصنوعی مستقل، رایگان و آفلاین-اول. هر پیام را می‌فهمد، **فکر می‌کند** و پاسخ واقعی می‌سازد؛ برنامه‌ها را **زنده و فایل‌به‌فایل** تولید می‌کند (بدون هیچ نمونه یا قالب آماده) و هر چیزی را که یاد می‌گیرد در پوشه `Learned/` ذخیره می‌کند.

## اجرا

```bash
python run.py
```

`run.py` خودش محیط مجازی می‌سازد، Flask را نصب می‌کند، موتورهای فکری و Node.js را تشخیص می‌دهد و مرورگر را باز می‌کند (`http://127.0.0.1:8585`).

## معماری: مغز واقعی، نه جواب آماده

Professor Flash یک مدل ترکیبی (Hybrid Agent) است:

| لایه | کار |
|---|---|
| موتور تفکر (LLM) | فکر کردن واقعی روی هر پیام - ساخت زنده کد، پاسخ به سوال، تغییر پروژه |
| هسته زبانی محلی | فهم فارسی (تکه‌کلام، احساسات، ترکیب فارسی-انگلیسی، اعداد) و مسیریابی |
| موتور محاسبه | ریاضی و فیزیک دقیق (عبارت، معادله، درصد، میانگین، فرمول‌های فیزیک) |
| دانش محلی | ~۳۵ مدخل واقعی فارسی (علم، برنامه‌نویسی، تاریخ، جغرافی، ریاضی) |
| جستجوی وب | DuckDuckGo برای متن + Wikimedia برای تصویر (بدون کلید) |
| یادگیری | `Learned/` - ذخیره غیرفعال دانسته‌های جدید، بازیابی سریع |

### موتورهای فکری (به ترتیب اولویت)

1. **Ollama** (محلی، کاملا آفلاین): اگر نصب باشد خودکار استفاده می‌شود. `ollama pull qwen2.5:7b`
2. **DeepSeek**: `set DEEPSEEK_API_KEY=...` قبل از اجرا
3. **OpenRouter**: `set OPENROUTER_API_KEY=...` (مدل‌های رایگان)
4. **Pollinations**: رایگان بدون کلید - در صورت در دسترس بودن خودکار استفاده می‌شود

اگر هیچ موتور فکری در دسترس نباشد، مغز محلی به کار ادامه می‌دهد: دانش، محاسبات دقیق، جستجوی وب و حافظه یادگیری؛ و برای «ساخت زنده» صادقانه می‌گوید به یک موتور فکری نیاز دارد و راهش را می‌گوید. هیچ پیامی از جواب آماده استفاده نمی‌کند.

## امکانات

- **فکر کردن مرحله‌به‌مرحله**: پنل Sandbox گام‌های فکر را زنده نشان می‌دهد (درک → تفکر → دانش → پاسخ)
- **ساخت زنده برنامه**: مدل فکری `index.html` + `style.css` + `app.js` را از صفر می‌نویسد، تست (`node --check`) می‌کند و خطا را خودش رفع می‌کند
- **سوال وسط کار**: اگر حین ساخت سوالی بپرسی، در صف می‌ماند و بعد از اتمام کار جواب می‌دهد - هیچ‌وقت با برنامه قاطی نمی‌شود
- **تغییر پروژه**: «رنگ دکمه‌ها را قرمز کن» واقعا روی همان فایل‌ها اعمال می‌شود
- **محاسبات دقیق**: معادله (خطی و درجه دوم)، درصد، میانگین، فیزیک (نیرو، سرعت، کار، انرژی، توان، مساحت، حجم)
- **تاریخچه**: چند گفتگو، حذف هر پیام، کپی هر پیام، بازگشت به گفتگوهای قبلی
- **کنترل**: توقف موقت (بعد از اتمام مرحله)، ادامه، توقف کامل
- **یادگیری**: دانسته‌های جدید در `Learned/` با فرمت JSON سبک (خوانا و سریع) ذخیره و بازیابی می‌شود
- **UI کاملا سیاه و حرفه‌ای**، راست‌چین، بدون ایموجی

```
run.py                 راه‌اندازی خودکار (venv، نصب، تشخیص، مرورگر)
app/server.py          Flask + API (تاریخچه، صف پیام، کنترل تسک)
app/brain/engine.py    مغز: مسیریابی، فکر کردن، ساخت، تغییر، سوال
app/brain/llm.py       زنجیره موتورهای فکری (Ollama/DeepSeek/OpenRouter/Pollinations)
app/brain/calc.py      ریاضی و فیزیک دقیق
app/brain/knowledge.py دانش محلی فارسی
app/brain/learn.py     یادگیری (Learned/)
app/brain/search.py    جستجوی وب و تصویر
app/brain/tester.py    تست واقعی کد (node --check)
app/static/            UI (index.html + css + js)
Learned/               دانسته‌های ذخیره‌شده توسط مدل
projects/              پروژه‌های ساخته‌شده
```
