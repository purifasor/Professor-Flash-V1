# ⚡ Professor Flash — پروفسور فلش

هوش مصنوعی **رایگان، آنلاین و زنده** — چت هوشمند + عامل کدنویس (Agent) که
مستقیم روی GitHub (مغز) و Vercel (محاسبات) اجرا می‌شود. بدون نصب، بدون
ثبت‌نام، بدون کلید.

A free, online AI — smart chat + an agentic code builder — running natively on
GitHub (the brain) and Vercel (the compute). No installs, no signups, no keys.

---

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| 💬 چت هوشمند | پاسخ‌های زنده و استدلال‌شده (نه متن آماده)، فارسیِ طبیعی، استریم واقعی |
| 🤖 حالت عامل | ساخت برنامه‌های چندفایلی کامل از روی توصیف فارسی/انگلیسی، با سینک خودکار فایل‌ها |
| 👁 پیش‌نمایش زنده | اجرای فوری برنامه ساخته‌شده در همان صفحه (سمت راست) + گزارش خطای زنده |
| 🛠 رفع خودکار | خطاهای رانتایم پیش‌نمایش خودکار برای عامل فرستاده می‌شود و فیکس می‌گیرد |
| ⬇ دانلود ZIP | خروجی یکجای همه فایل‌های پروژه |
| 🌐 جستجوی وب | دانش زنده از DuckDuckGo + ویکی‌پدیا برای سؤال‌های به‌روز |
| 🎨 حس طراحی | تم‌ها و پالت‌های نامدار (مثل فیروزه‌ای) را می‌شناسد و دقیق اعمال می‌کند |
| 🧠 مغز متصل به گیت‌هاب | شخصیت، مهارت‌ها و لیست مدل‌ها از پوشه `brain/` همین ریپو خوانده می‌شود |

## معماری

```
┌─ public/              فرانت‌اند (استاتیک، RTL، تم دارک، انیمیشن نرم)
│   ├─ index.html
│   ├─ css/styles.css
│   └─ js/{app,agent,markdown}.js
├─ api/                 بک‌اند (Vercel Serverless، Node)
│   ├─ chat.js          ← استریم SSE؛ حالت chat | agent (+ رفع خطای پیش‌نمایش)
│   ├─ search.js        ← جستجوی وب زنده
│   ├─ models.js        ← فهرست زنده موتورها
│   └─ _lib/
│       ├─ providers.js ← زنجیره موتورها (مسابقه استریم + fallback + مهار reasoning)
│       ├─ brain.js     ← ساخت پرامپت از brain/
│       ├─ search.js    ← DuckDuckGo + Wikipedia
│       └─ util.js
└─ brain/               🧠 مغز — ویرایش و push = بازآموزی رفتار
    ├─ persona.md         شخصیت و سبک پاسخگویی
    ├─ prompts/chat.md    قرارداد رفتار چت
    ├─ prompts/agent.md   پروتکل سخت‌گیرانه خروجی فایل + استاندارد کد/دیزاین
    ├─ skills/            reasoning · coding · design · research · communication
    ├─ knowledge/         پالت‌ها، وب بدون build، نکات فارسی
    └─ models.json        لیست موتورها (ترتیب = اولویت)
```

### موتورها (رایگان، بدون کلید، بدون ثبت‌نام)

ترتیب در `brain/models.json` — برای تعویض مغز فقط همین فایل را ویرایش و push کن:

1. **Kilo Gateway** — مدل‌های آزاد قدرتمند: `Nemotron 3 Ultra 550B`،
   `Nemotron 3 Super 120B`، `MiniMax M3` (کانتکست ۱ میلیونی)، `Step 3.7 Flash`،
   و برای حالت عامل مدل‌های تخصصی کدنویسی `North Mini Code` و `Laguna S/XS`.
2. **OVHcloud AI Endpoints** — `gpt-oss-120b`، `Llama-3.3-70B`، `Qwen3-Coder-30B` …
3. **Pollinations** — آخرین پشتیبان.

نکته فنی: مدل‌های هیبرید-reasoning به‌صورت خودکار با `reasoning:{enabled:false}`
صدا زده می‌شوند تا زنجیره استدلال داخل پاسخ لو نرود؛ مدل‌هایی که reasoning را
اجباری می‌کنند با `effort:low` ری‌ترای می‌شوند. موتورها در بچ‌های کوچک «مسابقه»
می‌دهند و اولین پاسخ سالم برنده است؛ مدل مشغول/ریت‌لیمیت کنار گذاشته می‌شود.

### قرارداد خروجی عامل

مدل فایل‌ها را با بلوک‌های ```` ```file:<path> ```` می‌سازد؛ فرانت‌اند همان
لحظه آن‌ها را parse می‌کند، درخت فایل را به‌روز می‌کند و پیش‌نمایش را می‌سازد
(CSS/JS محلی به‌صورت خودکار inline می‌شود). خطاهای رانتایم iframe به والد
postMessage می‌شوند و دکمه «رفع خودکار» آن‌ها را به عامل برمی‌گرداند.
