# Professor Flash V1

هوش مصنوعی مستقل، آفلاین و رایگان برای ساخت برنامه (AI App Builder)

Professor Flash یک مدل زبانی و عامل (Agent) محلی است که درخواست فارسی را می‌فهمد،
پروژه را فایل‌به‌فایل می‌سازد، تست می‌گیرد، خطا را رفع می‌کند و خروجی را در
مرورگر پیش‌نمایش می‌دهد — همه بدون اینترنت و بدون هیچ API آماده.

---

## اجرا

```bash
python run.py
```

`run.py` خودش همه کارها را انجام می‌دهد:

1. محیط مجازی (venv) می‌سازد
2. کتابخانه‌های لازم را نصب می‌کند (فقط Flask)
3. Node.js و Ollama را تشخیص می‌دهد (اختیاری)
4. سرور محلی را بالا می‌آورد
5. مرورگر پیش‌فرض ویندوز را باز می‌کند

پس از اجرا، برنامه در آدرس `http://127.0.0.1:8585` در دسترس است.

## امکانات

- **درک فارسی**: نرمال‌سازی متن (ي/ی، ك/ک، نیم‌فاصله، شکلک و تکه‌کلام‌ها)،
  تشخیص نیت (ساخت، تغییر، سوال، جستجو، محاسبه، توقف)، ترکیب فارسی و انگلیسی
- **ساخت زنده پروژه**: بازی مار، دوز، حدس عدد، آزمون، لیست کارها، یادداشت‌ها،
  بوم نقاشی، سایت و صفحه فرود، ساعت، کرنومتر، تولیدکننده رمز، مبدل واحد — هر کدام با
  `index.html`، `style.css` و `app.js` واقعی و کامل
- **شخصی‌سازی**: تم (تیره، سایبرپانک، نئون، شیشه‌ای، مینیمال، روشن) و رنگ
- **تغییر پروژه**: «رنگ دکمه‌ها را قرمز کن» — ساختار پروژه در حافظه می‌ماند و
  تغییر روی فایل واقعی اعمال می‌شود
- **تست و رفع خطا**: اگر Node نصب باشد `node --check` واقعی؛ در غیر این صورت
  بررسی ساختاری. خطاها به صورت خودکار رفع و بازسازی می‌شوند
- **جستجوی وب و تصویر**: بدون کلید API (DuckDuckGo و Wikimedia Commons).
  اگر اینترنت نبود، از مرحله رد می‌شود (Skip)
- **کنترل کامل**: دکمه توقف موقت (Pause) بعد از اتمام مرحله فعلی می‌ایستد؛
  دکمه ادامه (Resume) از همان‌جا ادامه می‌دهد؛ دکمه توقف کامل (Stop) جلوی هر
  کاری را می‌گیرد
- **حافظه یادگیری**: پروژه قبلی، اصلاحات و حقایق یادگرفته‌شده در `memory.json`
  ذخیره می‌شود و بعد از ری‌استارت هم ادامه می‌یابد
- **بدون فشار به سخت‌افزار**: هسته محلی سبک است؛ روی سیستم‌های ضعیف و لپ‌تاپ
  بدون گرافیک هم سریع اجرا می‌شود
- **بدون ایموجی در رابط**: طراحی حرفه‌ای دارک با آیکون‌های SVG

## ساختار پروژه

```
run.py                 ورودی: پیکربندی، نصب، اجرا و باز کردن مرورگر
app/
  server.py            سرور Flask + مدیریت وظیفه (Pause/Resume/Stop)
  static/              رابط کاربری (index.html, css/style.css, js/app.js)
  brain/
    persian.py         نرمال‌سازی و ابزار متن فارسی
    memory.py          حافظه ماندگار (پروژه، یادگیری، گفتگو)
    generator.py       ۱۰ قالب واقعی چندفایلی + اعمال تغییر
    engine.py          مغز: تشخیص نیت، ساخت، تغییر، سوال، جستجو، محاسبه
    tester.py          تست فایل‌ها (Node یا بررسی ساختاری)
    search.py          جستجوی وب و دانلود تصویر (با گزینه رد شدن)
projects/              پروژه‌های ساخته‌شده
memory.json            حافظه مدل
```

## توجه

Professor Flash یک مدل مستقل و ترکیبی (Hybrid) است: هسته زبانی محلی + تولید
کد زنده + حافظه یادگیری + جستجوی اختیاری. این یعنی همیشه آفلاین، رایگان و
سبک کار می‌کند. اگر Ollama روی سیستم نصب باشد، برای سوالات باز از آن به عنوان
شتاب‌دهنده محلی استفاده می‌شود (اختیاری).
