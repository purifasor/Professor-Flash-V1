# ⚡ Professor Flash — پروفسور فلش

هوش مصنوعی **رایگان، آنلاین و زنده** — چت هوشمند + عامل کدنویس (Agent) که
مستقیم روی GitHub + Vercel اجرا می‌شود. بدون نصب، بدون ثبت‌نام، بدون کلید.

A free, online AI — smart chat + an agentic code builder — running natively on
GitHub (the brain) and Vercel (the compute). No installs, no signups, no keys.

---

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| 💬 چت هوشمند | پاسخ‌های زنده و استدلال‌شده (نه متن آماده)، فارسیِ طبیعی، استریم واقعی |
| 🤖 حالت عامل | ساخت برنامه‌های چندفایلی کامل از روی توصیف فارسی/انگلیسی |
| 👁 پیش‌نمایش زنده | اجرای فوری برنامه ساخته‌شده در همان صفحه (سمت راست) |
| ⬇ دانلود ZIP | خروجی یکجای همه فایل‌های پروژه |
| 🌐 جستجوی وب | دانش زنده از DuckDuckGo + ویکی‌پدیا برای سؤال‌های به‌روز |
| 🎨 حس طراحی | تم‌ها و پالت‌های نامدار (مثل فیروزه‌ای) را می‌شناسد و اعمال می‌کند |
| 🧠 مغز متصل به گیت‌هاب | شخصیت و مهارت‌ها از فایل‌های همین ریپو خوانده می‌شود |

## معماری

```
┌─ public/            فرانت‌اند (استاتیک، RTL، تم تیره فیروزه‌ای)
│   ├─ index.html
│   ├─ css/styles.css
│   └─ js/{app,agent,markdown}.js
├─ api/               بک‌اند (Vercel Serverless، Node)
│   ├─ chat.js        ← استریم SSE؛ حالت chat | agent
│   ├─ search.js      ← جستجوی وب زنده
│   ├─ models.js      ← فهرست زنده موتورها
│   └─ _lib/
│       ├─ providers.js ← زنجیره موتورها (مسابقه + fallback)
│       ├─ brain.js     ← ساخت پرامپت از Model/Skills/Knowledge
│       ├─ search.js    ← DuckDuckGo + Wikipedia
│       └─ util.js
├─ Model/             🧠 مغز: persona، پروتکل عامل، فهرست موتورها
├─ Skills/            مهارت‌ها: reasoning · coding · design · research · communication
└─ Knowledge/         دانش مرجع: پالت‌ها، وب بدون build، نکات فارسی
```

### موتورها (رایگان، بدون کلید)

ترتیب در `Model/models.json` — برای تغییر مغز فقط همین فایل را ویرایش و push کن:

1. **OVHcloud AI Endpoints** — `Qwen3.5-397B-A17B` (۳۹۷ میلیارد پارامتر)،
   `gpt-oss-120b`، `Qwen3.8/3.6-27B`، `Llama-3.3-70B`، `Qwen3-Coder-30B` …
2. **Kilo Gateway** — استخر مدل‌های رایگان OpenRouter
3. **Pollinations** — آخرین پشتیبان

موتورها به‌صورت موازی «مسابقه» می‌دهند؛ اولین پاسخ سالم برنده می‌شود. اگر
مدلی محدودیت نرخ (rate-limit) داشت، به‌آرامی کنار گذاشته می‌شود و جایگزین
می‌گیرد — کاربر هرگز با بن‌بست «مشغول‌اند» روبه‌رو نمی‌شود.

### قرارداد خروجی عامل

مدل فایل‌ها را با بلوک‌های ```` ```file:<path> ```` می‌سازد؛ فرانت‌اند همان
لحظه آن‌ها را parse می‌کند، درخت فایل را به‌روز می‌کند و پیش‌نمایش را می‌سازد
(CSS/JS محلی به‌صورت خودکار inline می‌شود). اگر مدل پروتکل را رعایت نکند،
بک‌اند یک مرحله «اصلاح» اجرا می‌کند و فرانت‌اند هم parser جایگزین دارد.
