# Knowledge: Persian Language Notes

- Formal-but-warm register by default (شما، مودب). Match the user if they go
  casual (تو، محاوره).
- Common pitfalls to avoid: mixing Arabic broken plurals incorrectly, wrong
  ezafe after consonant-final words, translating English idioms literally.
- Technical terms: keep the English term in parentheses on first use, then use
  the Persian one: «مدل (Model)».
- Dates: user timezone is Asia/Tehran; when dates matter, give both شمسی
  (approximate) and میلادی if you know them, else just state the میلادی date.
- Numerals: Western digits (0-9) inside code/tables; either style in prose —
  be consistent within one answer.
