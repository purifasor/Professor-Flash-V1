# Knowledge — Professor Flash V1 بانک دانش

این پوشه بانک‌های اطلاعاتی آفلاین مدل Professor Flash V1 است.
مدل هنگام پاسخ‌گویی، بخش‌های مرتبط را بر اساس کلمات کلیدی پیام کاربر برمی‌دارد
و به متن ورودی موتور فکری (PRF) تزریق می‌کند؛ پس جواب‌ها دقیق‌تر، واقعی‌تر و
حرفه‌ای‌تر می‌شوند — بدون نیاز به اینترنت.

## فهرست بانک‌ها

| فایل | موضوع |
|------|-------|
| persian.md | تسلط بر زبان فارسی: دستور، چینش واژه، نگارش، نشانه‌گذاری، لحن |
| translation.md | ترجمه حرفه‌ای فارسی↔انگلیسی |
| communication.md | نحوه ارتباط، لحن، ساختار پاسخ، احوال‌پرسی |
| coding-python.md | الگوهای استاندارد کدنویسی پایتون |
| coding-web.md | HTML/CSS/JS: ریسپانسیو، انیمیشن، سئو، RTL |
| security.md | دانش فنی شبکه و امنیت (واقعی و کاربردی) |
| thinking.md | اصول تفکر PRF: تجزیه، حل مرحله‌ای، بازبینی |
| math-physics.md | فرمول‌ها و روش‌های محاسبه دقیق |
| design.md | اصول طراحی رابط تیره و مدرن |
| seo-dork.md | سئو و عملگرهای جستجوی پیشرفته (Google dork) |
| prompt-engineering.md | پرامپت‌نویسی حرفه‌ای |
| teaching.md | روش تدریس قدم‌به‌قدم |

## نحوه استفاده

- همه فایل‌ها Markdown ساده هستند و با کدنویسی UTF-8 ذخیره شده‌اند.
- هر فایل با عنوان `##` شروع می‌شود و بخش‌های موضوعی با `###` جدا شده‌اند.
- مدل با جستجوی واژه‌ای، بهترین بخش‌ها را انتخاب و به سیستم‌پرامپت اضافه می‌کند.
- هر دانش جدیدی که مدل یاد بگیرد، طبق همین قالب در این پوشه ذخیره می‌شود.
