# پرامپت‌نویسی حرفه‌ای

## ساختار پرامپت استاندارد
1. **نقش (Role)**: به مدل بگو کیست («تو یک مهندس ارشد پایتون هستی»).
2. **زمینه (Context)**: اطلاعات لازم را بده (پروژه، مخاطب، محدودیت‌ها).
3. **وظیفه (Task)**: دقیقاً چه چیزی می‌خواهی (فعل شفاف: بنویس، بساز، اصلاح کن).
4. **محدودیت‌ها (Constraints)**: قالب، طول، زبان، سبک، موارد ممنوع.
5. **قالب خروجی (Output format)**: شکل جواب (کد، جدول، لیست، JSON).

## اصول
- واضح و بی‌ابهام بنویس؛ «کوتاه» = چند خط، «مختصر» = یک پاراگراف.
- مثال بده: «مثلاً: ۱۲ و ۵ را جمع کن».
- اگر چند خواسته دارید، شماره‌گذاری کن.
- برای کد: زبان، ورودی/خروجی، و حالت خطا را مشخص کن.
- برای ترجمه: زبان مبدأ/مقصد و لحن (رسمی/صمیمی) را بگو.

## قالب آماده
```
تو یک [نقش] هستی.
[زمینه: پروژه/مخاطب/موقعیت]
وظیفه: [چه چیزی؟]
محدودیت‌ها: [زبان، قالب، طول، سبک]
خروجی: [فرمت دقیق خروجی]
مثال: [یک نمونه]
```

## مثال واقعی
```
تو یک توسعه‌دهنده ارشد وب هستی. یک ماشین‌حساب ساده می‌سازم.
وظیفه: فایل index.html، style.css و app.js کامل بساز.
محدودیت‌ها: تم تیره، ریسپانسیو، بدون کامنت، رابط فارسی با فونت Vazirmatn.
خروجی: سه فایل کامل با مارکر ===FILE: name===.
```

## نکات حرفه‌ای
- پرامپت‌های طولانی برای کارهای پیچیده، کوتاه برای کارهای ساده.
- از پرامپت منفی استفاده کن: «توضیح نده، فقط کد بده».
- برای اصلاح، همان درخواست قبلی + تغییر موردنظر را بنویس تا مدل ادامه دهد.
- «بهترین راه را انتخاب کن و خودت تصمیم بگیر» برای خواسته‌های باز.
