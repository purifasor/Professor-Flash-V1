# ریاضی و فیزیک

## حساب و جبر
- ترتیب عمل‌ها: پرانتز → توان → ضرب/تقسیم → جمع/تفریق.
- `%` باقی‌مانده، `//` تقسیم صحیح، `**` توان.
- اتحادها: `(a+b)² = a²+2ab+b²`؛ `a²-b² = (a-b)(a+b)`.
- معادله درجه دوم: `ax²+bx+c=0` → `x = (-b ± √(b²-4ac)) / 2a`؛ دلتا `Δ=b²-4ac`.
- درصد: `x% از y = (x/100)*y`؛ تغییر درصدی: `((جدید-قدیم)/قدیم)*100`.

## هندسه
- محیط/مساحت دایره: `2πr` / `πr²`؛ محیط/مساحت مستطیل: `2(a+b)` / `a*b`.
- مساحت مثلث: `(قاعده × ارتفاع) / 2`؛ ذوزنقه: `((a+b)/2) × h`.
- حجم: مکعب `a³`، مکعب‌مستطیل `a·b·c`، کره `(4/3)πr³`، استوانه `πr²h`.
- قضیه فیثاغورس: `c² = a² + b²`.

## فیزیک
- حرکت: `v = v₀ + at`، `x = v₀t + ½at²`، `v² = v₀² + 2ax`.
- نیرو: `F = ma` (نیوتن). وزن: `W = mg` (g≈9.8 m/s²).
- انرژی جنبشی: `K = ½mv²`؛ پتانسیل گرانشی: `U = mgh`؛ کار: `W = F·d·cosθ`.
- توان: `P = W/t` (وات)؛ `P = VI` در برق.
- قانون دوم نیوتن و تکانه: `p = mv`؛ ضربه = تغییر تکانه.
- مدار: `V = IR` (اهم)، توان `P = VI = I²R = V²/R`.

## اعداد و محاسبه
- عدد توان‌دار: `10³ = 1000`؛ `2¹⁰ = 1024`؛ لگاریتم: `log_b(a) = x` یعنی `b^x = a`.
- میانگین: مجموع ÷ تعداد؛ میانه: مقدار وسط مرتب‌شده؛ مد: پرتکرارترین.
- احتمال: `P = موارد مطلوب / کل موارد`؛ احتمال مستقل: ضرب.
- تبدیل: ۱ کیلومتر = ۱۰۰۰ متر؛ ۱ ساعت = ۳۶۰۰ ثانیه؛ ۱ مگابایت = ۱۰۲۴ کیلوبایت.

## محاسبه دقیق
- اعداد را با دقت کامل محاسبه کن و گرد نکن مگر لازم باشد؛ سپس گرد کن و بگو.
- اعشار تکراری: با کسر دقیق نگه دار (0.333 = 1/3).
- واحدها را همیشه بنویس و در جواب نهایی بیاور.
