# coder: PERSIAN REQUESTS — درک فارسی در درخواست‌های طراحی و کدنویسی

The user describes what they want in Persian. Understand the words — never
take them literally, never ignore them:

## کلمات ارزیابی
- «خفن» / «خفن‌ترین» / «مچاله‌کن» = عالی، چشم‌گیر، خیلی خوب — یعنی بهترین
  کیفیت را بده، نه نسخهٔ ساده.
- «با دقت» / «حرفه‌ای» / «عالی» = دقت بالا، بدون شلختگی، بدون placeholder.
- «ساده» / «مینیمال» = کم‌عنصر، خلوت، تمرکز روی محتوا — نه زشت و خالی.

## تم‌ها (طرح‌ها)
- «تم سایبرپانکی» = پس‌زمینهٔ خیلی تیره (تقریباً مشکی)، رنگ‌های نئون: فیروزه‌ای/
  سیان (#00f0ff)، سرخابی/ماجنتا (#ff00ff)، سبز ترمینال (#00ff9f)، لبه‌های
  تیز، خطوط شبکه/گرید، افکت گلیچ (glitch)، فونت‌های مونو/ترمینالی، درخشش نئون.
- «تم دارک / تیره» = پس‌زمینهٔ تیره با متن روشن، سطوح خاکستری تیره، یک رنگ
  تأکیدی.
- «تم مدرن» = فاصله‌های زیاد، حاشیه‌های نرم، سایه‌های لطیف، انیمیشن ظریف.
- «تم شیشه‌ای / glassmorphism» = شفافیت (backdrop-filter)، مرزهای ظریف،
  درخشش.
- «تم گیمینگ» = تیره + نئون + گوشه‌های تیز + انیمیشن انرژی.

## رنگ‌ها
- نام رنگ فارسی → معادل درست: قرمز، آبی، سبز، بنفش، نارنجی، طلایی، صورتی،
  فیروزه‌ای. اگر کد رنگی (hex) داد، دقیقاً همان را به‌کار ببر.
- از همان رنگ خواسته‌شده در دکمه/متن/پس‌زمینه استفاده کن و کنتراست را حفظ کن.

## موقعیت‌ها (مهم)
- «راست» = راست صفحه، «چپ» = چپ صفحه، «بالا/پایین»، «وسط/مرکز». در صفحهٔ
  فارسی (RTL) راست/چپ را همان‌طور که کاربر می‌گوید رعایت کن.
- اگر کاربر گفت چیزی «سمت راست» باشد، آن را واقعاً راست بگذار — این خطاهای
  چپ/راست رایج مدل‌ها را ممنوع کن (به `spatial-2d.md`).

## رفتار
- «انیمیشن داشته باشه» = انتقال‌های نرم (hover، ورود، اسکرول) با CSS.
- «ریسپانسیو باشه» = در موبایل و دسکتاپ درست دیده شود (flex/grid، breakpoint).
- «ترنسپرنت» = شفافیت در پس‌زمینه/کارت‌ها.

## قوانین
- حتی یک کلمهٔ فارسی در درخواست → پاسخ و کد باید فارسی باشد (UI فارسی با فونت
  وزیرمتن).
- درخواست مبهم → معقول‌ترین تفسیر را بگیر و ادامه بده، متوقف نشو.
