# coder — قابلیت‌های کدنویسی Professor Flash V1

این پوشه **کد نیست** — توانایی‌ها، سیستم پرامپت و درک‌های موردنیاز مغز برای
کدنویسی حرفه‌ای است. فایل‌های اینجا هر بار که کاربر کد/سایت/برنامه می‌خواهد،
به سیستم‌پرامپت تزریق می‌شوند تا مدل (هر مدلی که پشت PRF باشد) این توانایی‌ها را
به‌صورت passive داشته باشد:

| فایل | چه چیزی را آموزش می‌دهد |
|---|---|
| `prompt-system.md` | چرخهٔ کدنویسی: خواندن خواسته → برنامه → ساخت تک‌فایلی → بازبینی بدون خطا |
| `persian-requests.md` | درک فارسی: «خفن»، «تم سایبرپانکی»، رنگ‌ها، موقعیت‌ها، RTL |
| `design-sense.md` | حس طراحی: هماهنگی رنگ، کنتراست، بدون تداخل، ظاهر حرفه‌ای + تجسم |
| `spatial-2d.md` | درک مختصات ۲بعدی (x,y، چپ/راست، چیدمان CSS) — بدون جابه‌جایی اشتباه |
| `spatial-3d.md` | درک مختصات ۳بعدی (x,y,z در three.js و صحنه‌سازی) |
| `problem-solving.md` | حل مسئلهٔ کدنویسی پیچیده: تجزیه، الگوریتم، لبه‌ها، کد بدون ارور |

قوانین سراسری:
- کد خواسته‌شده در چت → **یک فایل کامل** (html+css+js و حتی کتابخانه‌ها در یک
  فایل؛ یا یک `.py`) — هرگز قطعه‌قطعه، هرگز ناقص، هرگز وسط کد قطع نشود.
- کد باید **واقعاً اجرا شود و بدون ارور** باشد؛ قبل از تحویل یک بار ذهنی اجرا و
  بازبینی کن.
- متن فارسی حتی با یک کلمه → جواب باید فارسی باشد.
