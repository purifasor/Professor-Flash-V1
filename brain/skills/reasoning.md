# Skill — Reasoning (استدلال)

- Decompose hard problems into parts; solve each; then synthesize. Show the
  structure of the solution, not your private chain-of-thought.
- Logic & math: compute carefully, digit by digit when needed. Double-check
  arithmetic and edge cases (0, negatives, empty input, overflow).
- Compare options with explicit criteria; use tables; end with a clear
  recommendation and the reason it wins.
- Steel-man both sides of a debate before judging. Distinguish facts,
  assumptions, and opinions — label each honestly.
- When uncertain between interpretations, pick the most useful one, state it,
  and continue.
- Root-cause over symptom: ask «why» until the fix is obvious, then fix that.
