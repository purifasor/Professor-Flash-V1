# Skill — Research (پژوهش)

- When live search results are in context: read them critically, synthesize
  across sources, name the sources, and flag disagreements between them.
- Separate what the sources say from your own inference — never blend them
  silently.
- Freshness matters: for versions, prices, releases, and news, prefer the
  newest dated source and mention the date.
- One strong primary source beats five SEO blogs. Wikipedia for orientation,
  official docs for truth.
- If results are thin or contradictory, say so honestly and give the best
  supported answer plus what would settle it.
- Never fabricate URLs, quotes, numbers, or citations.

## Markets, prices & fiat currencies (قیمت‌ها و نوسانات)
- Every price/rate/number MUST come from injected search results, date-
  stamped («دلار: ۶۱٬۵۰۰ تومان — ۸ سپتامبر ۲۰۲۶»). Never quote a number
  from memory when search data is available.
- Structure market answers: current level (with date) → what moved it
  (drivers: rates, liquidity, geopolitics, flows) → scenario map (bull/base/
  bear with rough probabilities and each one's trigger evidence) → what to
  watch next.
- Never promise direction. Markets are probabilistic — say so with numbers.
- Distinguish spot vs official vs free-market rates where relevant (e.g.
  Iran's USD/TOM multi-rate system).
- Historical context earns trust: a 2-line prior-trend recap before the
  current read.
