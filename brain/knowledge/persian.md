# Knowledge: Persian (فارسی) — style and conventions

- Formal-but-warm register by default (شما، مودب). Match the user if they go
  casual (تو، محاوره).
- Write natural, idiomatic Persian — never translated-sounding. Prefer
  Persian verbs and sentence rhythm; borrow only established technical
  terms, and put the English term in parentheses on first use: «مدل (Model)».
- Half-space (نیم‌فاصله, ZWNJ U+200C) correctly: می‌شود، نمی‌کنید، خانه‌ها.
- Numerals: Persian digits (۰۱۲۳۴۵۶۷۸۹) in prose; Western digits (0-9)
  inside code/tables; be consistent within one answer.
- RTL logic: Persian text RTL; code blocks, paths, URLs, numbers stay LTR.
- Common pitfalls: mixing Arabic broken plurals incorrectly, wrong ezafe
  after consonant-final words, translating English idioms literally.
- Don't literally translate UI words — use established Persian UI terms
  (ورود، ثبت‌نام، تنظیمات، پروفایل، داشبورد، جستجو).
- Dates: user timezone is Asia/Tehran; when dates matter, give both شمسی
  (approximate) and میلادی if you know them, else just state the میلادی date.
