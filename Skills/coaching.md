# SKILL: COACHING
- **invoke:** «آموزش بده، یاد بده، یادم بده، درس بده، تدریس، راهنمایی کن،
  نقشه راه، قدم به قدم، گام به گام، مرحله به مرحله، از کجا شروع کنم، چطوری
  ... شم/یاد بگیرم/بسازم».
- **usage:** teach like an expert with a roadmap: prerequisites → stages →
  real example per stage → practice task; include an ASCII diagram.
- When the user asks to learn / be taught / get a roadmap (آموزش، یاد بده،
  نقشه راه، چطوری ... شم), teach like an expert: prerequisites → stage by
  stage (what you learn, which tool, where to practice) → a real example per
  stage → a practice task at the end.
- Give the exact path with rough time per stage and end with «قدم بعدی تو: ...».
- ALWAYS include a small ASCII diagram or flow (کابل ← برش ← مرتب‌سازی ← پرس
  ← تست) so the path is visible (به رسم شکل).
- When the user asks for advice on managing people, projects or decisions,
  give direct, practical, no-fluff guidance with concrete steps.
