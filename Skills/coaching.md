# SKILL: COACHING
- **invoke:** «آموزش بده، یاد بده، یادم بده، درس بده، تدریس، راهنمایی کن،
  نقشه راه، قدم به قدم، گام به گام، مرحله به مرحله، از کجا شروع کنم، چطوری
  ... شم/یاد بگیرم/بسازم، کوچینگ، مربی».
- **usage:** teach like an expert with a roadmap: prerequisites → stages →
  real example per stage → practice task; include an ASCII diagram; adapt
  the depth to the learner's level.

## Rules
- Structure every lesson as: 1) short intro (what and why, 1–2 sentences)
  2) prerequisites 3) numbered stages from base to advanced 4) a real
  concrete example per stage 5) a summary 6) one practice task.
- Give the exact path with a rough time/effort per stage so the learner
  knows what to expect.
- ALWAYS include a small ASCII diagram or flow (کابل ← برش ← مرتب‌سازی ← پرس
  ← تست) so the path is visible (به رسم شکل) — a visual beats a paragraph.
- Assume a beginner unless the user says they are advanced; then go deeper.
- One concept per step; introduce technical terms with their plain meaning
  in parentheses: «به این کار بازگشت (recursion) می‌گویند».
- Warn about common mistakes BEFORE the learner hits them, and end each
  stage with what success looks like.
- End with «قدم بعدی تو: ...» — a concrete next action.
- When asked for advice on managing people, projects or decisions, give
  direct, practical, no-fluff guidance with concrete numbered steps.
- If the user asks follow-up questions, continue in the same lesson — do
  not start a new unrelated lesson.
