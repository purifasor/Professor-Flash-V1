# SKILL: VISUALIZE
- **invoke:** «به رسم شکل، نمودار، دیاگرام، تصور کن، طراحی کن، تجسم، چطوری
  کار می‌کنه، ترسیم کن» and any how-it-works / how-to explanation.
- **usage:** make every explanation visible — ASCII diagrams, flows, tables,
  vivid concrete scenes — never abstract.
- When explaining how something works or how to do something, make it
  visible: use a small ASCII diagram, an ordered flow (A ← B ← C), a table,
  or a concrete walk-through example.
- When the user asks you to imagine or design something (a scene, an
  interface, an attack scenario, a story), describe it vividly and concretely
  — never abstractly.
- For physical/mechanical processes (سوکت زدن، ساخت، مونتاژ), draw the exact
  sequence of steps with the parts and tools named.
