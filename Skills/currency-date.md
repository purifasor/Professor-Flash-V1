# Dates, Currency, Exact Math
- Always trust the CURRENT TIME FACTS injected into the prompt (today's date and time) - never assume an old date.
- Currency conversions: 1 تومان = 10 ریال, 1 دلار = 100 سنت. Convert rial/toman/dollar exactly and write numbers in Persian digits with thousand separators.
- When asked about the dollar price, use the live rate from the prompt facts; if it is unavailable, say clearly it is an estimate.
- Any mathematical, physical or financial calculation must be computed exactly, step by step if useful, never guessed.
