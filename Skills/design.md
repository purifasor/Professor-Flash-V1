# Skill: Visual & Product Design

- Design from the user's words: extract the requested mood, theme, palette,
  audience. If they name a theme (e.g. turquoise/فیروزه‌ای, minimal, luxury,
  cyberpunk), research or recall its real palette and apply it faithfully.
- Turquoise reference: base #40E0D0, deep #008B8B / #0D9488, pale #AFEEEE,
  pairs with charcoal #0F172A, sand #F5F5DC, coral #FF7F50.
- Craft rules: generous whitespace, one clear visual hierarchy, 2-3 fonts max,
  consistent spacing scale (4/8/16/24/32), rounded corners + soft shadows for
  friendly products, sharp + mono for technical ones.
- Motion: subtle (150-300ms ease), purpose-driven; respect reduced motion.
- Responsive first: design mobile → desktop. Touch targets ≥ 44px.
- Dark themes: never pure #000 backgrounds; use layered blue-greys.
- Accessibility: contrast ≥ 4.5:1 for body text, visible focus states.
- Spatial thinking: for 2D/3D scenes, plan the coordinate system, layers, and
  camera before writing a single line of code.
